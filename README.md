## 🚀 How to Publish to GitHub Pages (Step-by-Step)

### Option 1: Using Git via Terminal / Command Prompt

1. **Initialize Git inside this folder**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: LoomX Mill fabric supplier website"
   ```

2. **Create a new repository on GitHub**:
   - Go to [github.com/new](https://github.com/new).
   - Enter repository name (e.g., `loomx-mill` or `fashway-site`).
   - Leave it **Public** (required for free GitHub Pages).
   - Do **NOT** check "Initialize with a README" (you already have one).
   - Click **Create repository**.

3. **Link and push to GitHub**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```

4. **Activate GitHub Pages**:
   - On GitHub, navigate to your repository's **Settings** tab.
   - In the left sidebar, click **Pages**.
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/ (root)`.
   - Click **Save**.
   - Within 1–2 minutes, your website will be live at:
     ```
     https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/
     ```

### Option 2: Using GitHub Desktop

1. Open **GitHub Desktop**.
2. Click **File > Add local repository...** and select `c:\Users\HP\Desktop\fashway-site`.

4. Go to your repository settings on GitHub.com and enable **GitHub Pages** (Settings > Pages > Branch `main` > Save).
